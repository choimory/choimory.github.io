# 변경 범위와 유지 항목

- 콘텐츠 변경 대상은 `_posts/knowledge/**/*.md`로 한정했다.

- 디렉터리·패키지 구조, 명령어 출력, 단순 설명·비교·정책 목록과 프로그래밍 언어 코드 블록은 유지했다.
- Mermaid 소개 글의 기존 문법 예제 4개도 유지했다.
- README에는 현재 Mermaid 활성화 방법, 코드 블록 예시, 표시 설정과 검증 방법을 기술 설명으로 반영했다. 작업 히스토리는 README에 기록하지 않았다.

# 표시 설정과 한계

- 사이트의 다크 배경에서 연결선·설명 대비가 낮아지는 문제를 보완하기 위해 도식별 `config.theme: dark`를 적용했다.
- 넓은 도식이 모바일에서 지나치게 축소되지 않도록 도식 유형별 `useMaxWidth: false`를 적용했다. 넓은 내용은 도식 영역 안에서 가로 스크롤한다.
- 현재 테마 설정은 도식별 고정값이다. 블로그를 라이트 모드로 바꾸어도 도식은 다크 테마로 유지된다.
- 동일한 설정이 여러 도식에 반복된다. 사이트 테마를 따라가도록 공통 초기화 부분을 개선하는 방안은 후속 검토 사항이며, 이번 작업에서는 구현하지 않았다.
