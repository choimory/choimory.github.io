# 텍스트 다이어그램 전수조사

> 전수조사 ㄱㄱ

## 조사 범위와 결과

최초 조사에서는 게시글 175개를 포함해 저장소의 문서·HTML 215개를 조사했다. Git 내부 파일, 빌드 생성물과 외부 의존성 디렉터리는 제외했다.

코드 블록의 박스 문자와 화살표, ASCII 도식, 블록 언어 지정과 코드 블록 밖의 흐름 표현을 확인했다.

| 구분 | 최초 조사 결과 |
|---|---:|
| 일반 텍스트 블록의 교체 검토 후보 | 45개 게시글, 415개 블록 |
| 다른 언어로 지정된 추가 후보 | 5개 블록 |
| 이미 Mermaid 문법으로 작성된 예제 | 1개 게시글, 4개 블록 |
| README·규칙·과거 히스토리의 후보 | 6개 문서, 14개 블록 |

후보 수는 확정 교체 수가 아니다. 디렉터리 트리, 단순 대응 관계, 설명문도 포함되어 있으므로 실제 교체 범위를 정할 때 개별 판단이 필요하다. 최초 조사는 저장소 전체를 대상으로 했으며, 현재 작업 범위는 뒤의 범위 조정 내용을 따른다.

## 추가 발견 사항

- `→`, 박스 문자 외에도 `|`, `v`, `+--`로 그린 ASCII 도식이 있다. MySQL 레플리카·Traefik·Tailscale 글에서 추가로 발견했다.
- OAuth 인증 흐름은 `markdown`, 권한 관계는 `yaml`, Helm 디렉터리 구조는 `kotlin`으로 지정되어 있다. 블록 언어만으로 대상을 고르면 누락될 수 있다.
- API 버전 변경 관계는 `scss`로 지정되어 있다. 다른 언어로 지정된 추가 후보 5개는 OAuth 흐름 1개, 권한 관계 1개, Helm 디렉터리 구조 2개, API 버전 변경 관계 1개다.
- 코드 주석과 본문에 포함된 화살표는 다이어그램 여부를 구분해야 한다. 코드 블록 밖의 화살표 표현도 확인했으며, 일반 설명까지 일괄 교체하는 것은 권장하지 않는다.

## Mermaid 사용 및 설정 현황

- 현재 테마는 `jekyll-theme-chirpy` 7.6.0이다.
- Mermaid 소개 글의 예제 4개는 이미 Mermaid 문법이지만 코드 블록에 언어 지정이 없다.
- 해당 예제는 Flowchart 2개, Sequence Diagram 1개, ER Diagram 1개다.
- 조사 당시 `_config.yml`과 게시글에 `mermaid: true` 설정이 없고, `mermaid` 언어가 지정된 코드 블록도 없었다.
- 실제 교체 시 테마의 Mermaid 활성화 방식과 렌더링 설정을 확인해야 한다.
- 호스트 환경에는 잠금 파일에서 요구하는 Bundler 2.7.1이 없어 `bundle show jekyll-theme-chirpy`로 테마 내부 구현을 확인하지 못했다. 테마 내부 렌더링 동작은 아직 검증하지 않았다.

## 권장 작업 범위

다음은 최초 조사 결과에 따른 제안이며, 확정된 구현 범위는 아니다.

- 시스템 구조·통신 흐름·분기·계층 관계를 우선 Mermaid로 교체한다.
- 디렉터리 트리와 명령어 출력, 코드 설명용 화살표는 유지하는 편을 권장한다.
- 과거 히스토리와 공통 규칙 문서는 교체 범위에서 제외하는 편을 권장한다.
- Mermaid 소개 글의 기존 예제는 문법 설명 목적을 고려해 언어 지정과 렌더링 방식을 검토한다.
- 교체 대상으로 확정한 블록은 원문의 구성 요소, 연결 방향, 분기 조건과 설명을 보존한다.

# 대상 범위 조정 및 재집계

> 일단 대상은 _posts/knowledge에 있는 마크다운 글들만 대상이니까 html, kotlin은 필요없음
> 변경대상이 되는 마크다운 글들이 몇개가 되는지 확인해봐

## 현재 대상 범위

- 변경 대상 파일은 `_posts/knowledge` 아래의 마크다운 글로 한정한다.
- `_posts/experiences`, HTML 파일, README, 공통 규칙과 과거 히스토리 문서는 교체 대상에서 제외한다.
- 이번 재집계에서는 언어 미지정 또는 `text`, `plaintext`, `plain`인 코드 블록을 조사했다. `kotlin` 등 프로그래밍 언어로 지정된 코드 블록은 제외했다.
- 위 코드 블록 기준은 재집계에 적용한 기준이다. 최초 조사에서 발견한 다른 언어 지정 후보 5개도 이번 재집계 수치에는 포함하지 않았다.

## 변경 후보 게시글 수

| 구분 | 재집계 결과 |
|---|---:|
| `_posts/knowledge` 전체 마크다운 글 | 163개 |
| 텍스트 다이어그램 교체 후보가 있는 글 | 43개 |
| 해당 글의 후보 블록 | 406개 |
| 기존 Mermaid 문법 예제가 있는 글 — 별도 집계 | 1개, 4개 블록 |
| 기존 Mermaid 예제의 언어 지정 수정까지 포함할 경우 | 총 44개 글 |

최초 일반 텍스트 후보 45개 게시글·415개 블록에서 `_posts/experiences`의 2개 글·9개 블록을 제외한 결과가 43개 글·406개 블록이다.

기존 Mermaid 예제는 `_posts/knowledge/2026-07-20-Mermaid & Mermaid vs Python Diagrams.md`에 있으며, 텍스트 도식의 신규 변환과 구분해 집계했다.

## 집계 해석과 현재 상태

- 43개는 변경 검토 후보 글 수다. 디렉터리 트리·단순 설명도 후보에 포함되어 있어 이를 유지하면 실제 변경 글 수는 줄어들 수 있다.
- 기존 Mermaid 예제가 있는 글의 언어 지정까지 수정할지는 아직 확정하지 않았다.
- 조사 결과와 대상 범위 조정을 문서에 기록한 상태이며, 실제 다이어그램 교체와 설정 변경은 수행하지 않았다.
- 빌드·테스트와 브라우저 렌더링 검증은 수행하지 않았다.
- 작업 상태는 `PLAN`으로 유지한다.
