# 파비콘 구성 및 원본 이미지 분석

> 분석 ㄱㄱ

## 분석 결과

지정한 사진으로 파비콘을 교체할 수 있다. 브라우저 파비콘뿐 아니라 홈 화면 및 PWA 설치용 아이콘도 함께 교체하는 구성을 권장한다.

| 항목 | 확인 결과 |
|---|---|
| 원본 파일 | 같은 작업 디렉터리의 `images_(38).jpg` |
| 이미지 크기 | 443×332px |
| 이미지 형식 | JPEG, RGB, 투명 배경 없음 |
| 이미지 특징 | 노란 배경에 캐릭터 얼굴과 양옆 신체 일부가 보이는 가로형 이미지 |
| 현재 테마 | Chirpy 7.6.0 |
| 프로젝트 자체 파비콘 | 별도 파일 없이 테마 기본 아이콘 사용 |

## 현재 파비콘과 PWA 구성

테마의 `_includes/favicons.html`과 기존 빌드 결과를 확인했다. 아이콘 경로는 `/assets/img/favicons/`이며, 다음 파일이 연결되어 있다.

| 파일 | 연결 용도 |
|---|---|
| `favicon-96x96.png` | 96×96 PNG 파비콘 |
| `favicon.svg` | SVG 파비콘 |
| `favicon.ico` | 브라우저 shortcut icon |
| `apple-touch-icon.png` | 180×180 홈 화면 아이콘 |
| `site.webmanifest` | PWA manifest |
| `web-app-manifest-192x192.png` | PWA용 192×192 아이콘 |
| `web-app-manifest-512x512.png` | PWA용 512×512 아이콘 |

- `_config.yml`의 `pwa.enabled`와 `pwa.cache.enabled`는 모두 `true`다.
- 현재 manifest는 사이트 이름과 설명을 사이트 설정에서 가져오고, 192×192 및 512×512 PNG를 참조한다.
- 512×512 아이콘에는 `purpose: maskable`이 지정되어 있다.
- SVG 연결이 별도로 존재하므로 PNG와 ICO만 교체하면 일부 브라우저에서 테마 기본 SVG 아이콘이 계속 표시될 수 있다.

## 권장 이미지 가공 방향

- 원본 `images_(38).jpg`는 보존한다.
- 얼굴을 중심으로 정사각형으로 자르고, 작은 파비콘에서도 알아볼 수 있도록 구도를 잡는다.
- 가로형 원본을 정사각형으로 단순 변형해 비율이 찌그러지지 않도록 한다.
- 작은 브라우저 파비콘과 큰 설치용 아이콘의 가독성을 각각 확인한다.
- 512×512 설치용 아이콘은 마스크 적용 시 얼굴이 잘리지 않도록 여백을 고려한다.

## 교체 파일과 적용 방법

다음은 분석에 따른 권장 계획이며, 아직 적용하지 않았다.

### 생성할 아이콘

프로젝트의 `assets/img/favicons/`에 다음 파일을 배치한다.

| 파일 | 규격 및 용도 |
|---|---|
| `favicon.ico` | 16×16, 32×32, 48×48 크기를 포함한 브라우저 아이콘 |
| `favicon-96x96.png` | 96×96 PNG 파비콘 |
| `apple-touch-icon.png` | 180×180 홈 화면 아이콘 |
| `web-app-manifest-192x192.png` | 192×192 PWA 아이콘 |
| `web-app-manifest-512x512.png` | 512×512 PWA 설치용 아이콘 |

### 테마 기본 연결 덮어쓰기

- 프로젝트에 `_includes/favicons.html`을 추가해 테마 기본 include를 덮어쓴다.
- JPG 원본을 기반으로 PNG·ICO를 사용하며, 테마 기본 `favicon.svg` 연결은 제거한다.
- PNG·ICO·Apple Touch Icon 연결을 유지하고, PWA가 활성화된 경우 manifest를 연결한다.
- URL 생성에는 테마와 동일하게 `relative_url`을 사용해 사이트 경로 설정을 반영한다.
- `_site`는 빌드 생성물이므로 직접 수정하지 않는다.

### PWA manifest

- 프로젝트에 `assets/img/favicons/site.webmanifest`를 추가해 아이콘 연결을 관리한다.
- 사이트 이름·설명과 시작 URL은 현재 테마의 사이트 설정 연동 방식을 유지한다.
- 192×192·512×512 아이콘을 새 이미지로 교체한다.
- 512×512 파일은 현재 `maskable` 용도를 고려해 구도를 구성한다.

## 검증 계획

1. 생성한 PNG의 크기·형식과 ICO에 포함된 해상도를 확인한다.
2. Jekyll 빌드 후 페이지의 아이콘 링크와 manifest의 파일 경로를 확인한다.
3. 테마 기본 SVG를 참조하는 링크가 남아 있지 않은지 확인한다.
4. 브라우저 탭과 홈 화면·설치용 아이콘의 표시를 확인한다. 실제 기기 확인이 필요한 항목은 검증 범위를 구분해 보고한다.
5. PWA 마스크 적용 시 얼굴이 잘리지 않는지 확인한다.
6. 기존 방문자의 캐시로 이전 아이콘이 보일 수 있으므로 새 브라우저 환경에서도 확인한다.

## 현재 진행 상태

- 원본 이미지와 현재 테마·PWA의 아이콘 연결 구성을 읽기 전용으로 분석했다.
- 이미지 가공, 아이콘 생성, include 및 manifest 수정은 수행하지 않았다.
- 구현 후 빌드·표시 검증은 아직 수행하지 않았다.
- 작업 상태는 `PLAN`으로 유지한다.

# PWA의 의미와 아이콘 용도

> pwa가 뭐임?

PWA는 Progressive Web App의 약자로, 웹사이트를 앱처럼 설치해서 사용할 수 있게 하는 방식이다.

휴대폰 홈 화면이나 PC에 사이트를 설치하고, 브라우저 탭 대신 별도 창으로 실행할 수 있다. 설정에 따라 일부 내용을 캐시해 오프라인에서도 보여줄 수 있다.

이 블로그는 현재 PWA 기능이 활성화되어 있다. 파비콘 관련 이미지는 표시 용도에 따라 나뉜다.

- 파비콘: 브라우저 탭에 표시되는 작은 아이콘.
- PWA 아이콘: 사이트를 설치했을 때 홈 화면이나 앱 목록에 표시되는 아이콘.

이번 계획에서 192×192·512×512 아이콘도 함께 교체하려는 이유는 설치용 아이콘까지 같은 이미지로 맞추기 위해서다.

# 브라우저 탭과 홈 화면의 의미

> 브라우저, 홈화면은 뭐임?

여기서 브라우저 탭과 홈 화면은 아이콘이 표시되는 위치를 뜻한다.

- 브라우저 탭: 크롬·사파리에서 블로그를 열었을 때 탭의 페이지 제목 옆에 뜨는 작은 아이콘이다.
- 홈 화면: 휴대폰에서 블로그를 '홈 화면에 추가'했을 때 다른 앱 아이콘처럼 바탕화면에 생기는 바로가기 아이콘이다.

같은 사진을 사용하되, 표시되는 위치에 맞춰 크기와 파일 형식을 다르게 준비한다.
